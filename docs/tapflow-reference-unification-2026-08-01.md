# Tapflow / 生产画布参考资产贯穿约束

## 不可破坏的约束

面板参考选择、现有 `InfiniteMediaCanvas`、Tapflow 不得各自保存一份参考资产数组。三者共同使用 `content_reference_links` 表达“哪个业务对象因为什么用途引用哪个资产”；URL 和名称只是快照，稳定身份优先使用 `element_id`、`attachment_id` 或 `canvas_slug + node_key`。

媒体文件仍由素材库（`content_attachments`）管理，文本提示词、模型参数和节点产物仍属于画布实例/版本/运行记录。文本不是素材文件，不自动进入素材库；只有被明确复用为知识、模板或业务要素时才单独建模。

## 兼容期读写规则

- 面板与旧无限画布继续写 `content_nodes.meta.element_ids / extra_refs / ref_off`，写完立即同步 `content_reference_links`。
- 新入口通过统一引用 API 写关系时，同时镜像旧字段，旧面板无需升级即可看到。
- 展示与生成时统一调用引用解析服务，按稳定身份读取要素/素材的最新 URL；生成运行记录保留当次快照用于追溯。
- 场景组空间图、故事板等非普通要素引用也进入关系表，不只同步角色/场景要素。
- 图片、视频、音频可归入素材库；文本提示词和生成配置保存在节点状态、画布实例版本及运行记录中，不作为素材库附件。

## 分镜首帧旁路对比

新增工作流 `shot-keyframe-canvas`，入口位于现有分镜首帧无限画布的“Tapflow 资产贯穿对比”按钮。它只作为旁路画布存在，不替换 `ShotSopCanvas / InfiniteMediaCanvas`；最终仍执行 `gen_keyframe` 并回写原分镜首帧字段。

验收步骤：

1. 在面板增加或移除一个要素/素材参考，保存后打开旧无限画布，名单应一致。
2. 从旧无限画布增加或移除参考，关闭再打开，面板应同步一致。
3. 打开 Tapflow 对比入口，`分镜数据与统一参考资产` 节点及首帧生成节点的参考列表应与前两处一致。
4. 修改要素设定图 URL 后无需重建关系，三处应解析到新 URL；历史运行仍能从快照追溯当次输入。
5. Tapflow 生成首帧后，旧分镜卡和旧无限画布应显示同一个 `keyframe_url`。
