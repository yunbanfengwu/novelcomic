# 拆分镜到真实视频:关键点清单(定稿 · 2026-07-09)

> 本文汇总 2026-07-09 用户逐轮纠正沉淀出的**全链路关键点**:每条 = 病灶 → 决策 → 落点(代码/知识库)。这是"分镜专业度"的操作手册,细节规范见 [storyboard-prompt-spec.md](storyboard-prompt-spec.md),金标准样例见 [../samples/storyboard-golden-sample.md](../samples/storyboard-golden-sample.md)。

## TL;DR

12 条关键点分四组:**颗粒度**(1-2)、**知识驱动**(3-5)、**生成链**(6、9、12)、**节奏与运动**(7-8、10-11)。核心一句话:**剪辑口径拆节奏(ASL 3-4s),生成口径合镜头组(同场快切一次生成),知识库出专业词,校验 Gate 兜底,彩色首帧锁画风。**

## 一、提示词颗粒度

**1. 叙事层全保留,技术层效果化转译**
- 病灶:拉片级参数(T值/灯具)模型读不懂;纯白话描述又不专业。
- 决策:景别/角度/运镜/焦段感原样进提示词(模型有统计响应);光圈→"浅景深",灯具方案→"该灯产生的画面效果"(256 盏 Fresnel 环形追逐 → "环绕流动的水波光")。
- 落点:kb `lens`/`lighting` 轴;spec §一。

**2. AI 视频三硬约束**
- ①一镜只写**一个相机动作+一个主体动作**(复合运镜必崩);②单镜 2-8s(镜头组 5-10s);③**两段式**:彩色首帧提示词含全部静态信息,视频提示词只写运动增量、主体动作永远最前(前 20-30 词权重最高)。
- 落点:铁律 2/3;校验 G4;`assemble_shot_prompts`。

## 二、知识驱动(专业度不靠模型即兴)

**3. 员工=四层装配,技能必须落库**
- 病灶:方法论硬编码在 Python 里,UI"技能"页为空,用户无法调整。
- 决策:系统提示词 = 章程(agents 表)+ 技能(kb kind=skill,项目覆盖全局)+ 知识块(按镜召回)+ 项目偏好(级联);枚举与输出格式由代码强制(校验单一来源)。全局技能随代码升级同步,用户自定义走项目级复制。
- 落点:`_director_system`/`_writer_system`;`knowledge_seed._seed_skills`。

**4. 知识块按镜内容召回**
- 每镜标注的 `scale/angle/lens_feel` 精确取块,`lighting/motion_hint/mood` trgm 情境召回,画风按项目 art_style 召回——prompt 是编译产物。
- 落点:`assemble_shot_prompts` + kb 9 轴(camera/angle/lens/lighting/camera_move/motion/pace/style/sheet)。

**5. 分镜必须关联核心要素(不能只挂章节)**
- 病灶:参考图无法按镜召回。
- 决策:拆镜时解析出场角色+场景 → `meta.element_ids` + `element_appearances`(shot 级,shot 也是 content_nodes,检索路④天然支持);装配器按 id 取要素,角色外貌进身份层(每镜必注入),设定图 URL 进 reference_images。
- 落点:`breakdown_chapter`/`assemble_shot_prompts`。

## 三、生成链

**6. 故事板双轨:彩色首帧是正轨**
- 病灶:黑白故事板作 I2V 首帧必出黑白片(实测)。
- 决策:黑白板=可选人审预览(不进生成链);生产链=彩色首帧关键帧(`gen_keyframe`)→ I2V;**画风三重锁**:style 块入首帧提示词 + 关联要素设定图作参考 + 视频提示词画风锚词。九宫格(`POST /chapters/{id}/storyboard-grid`)是表达层工具,一张 3×3 黑白格审全场构图节奏。
- 落点:worker `gen_keyframe`;shots API;kb sheet「分镜九宫格」。

**9. 同场快切=镜头组(cuts),不拆独立任务** ★大殿对话问题的答案
- 病灶:对话场每 1-2s 正反打,若拆成 N 个独立生成任务——量大、贵、且各任务间人物占位/光线必然漂移。
- 决策:剪辑上是十几个镜头,**生成上是 1-2 次**:一个 shot=一个生成单元(5-10s),`cuts` 数组表达组内硬切(每切 1-3s,景别远近交替,标注主体角色);视频提示词用多镜头叙事语法("首镜[特写]角色A…切镜头:[全景]大殿…"),**组内一致性由同一次生成上下文天然保证**;跨组一致性靠首帧+设定图。只有场景/时间跳变才另起新镜。
- **实测教训(2026-07-09 大殿对话专项)**:铁律写进提示词后模型仍不自觉输出 cuts(12 个独立单镜)——再次验证"确定性骨架,不靠模型自觉":合并改为**零 token 确定性后处理** `merge_dialogue_groups`,同场景连续对话/反应短镜 ≥2 个自动打包(≤5切/≤10s 分批,首切定首帧构图,对白并入各切 action);模型自带 cuts 时原样尊重。
- 落点:铁律 12;G14;`merge_dialogue_groups`/`_make_group`;`cuts` 渲染进 video_prompt。

**12. 一致性是系统工程**
- 身份层文本(每镜)+ 设定图参考(按镜关联要素)+ 彩色首帧锚定(I2V)三管齐下;视频提示词固定追加"同一角色,面部稳定不变形,服装不变"。
- **引用式身份层必须与实际附件同生死**(2026-07-09 实测踩坑):提示词写"造型以参考图为准"但降级路径没传图 → 模型凭空发明角色。解法:装配器产出双版视频提示词(`video_prompt` 引用版 / `video_prompt_textonly` 外貌全文版),worker 降级到零输入图时自动切换全文版。
- 后续增强:跨组首尾帧链(前组尾帧作后组首帧,FLF)。

## 四、节奏与运动(视觉疲劳的解药)

**7. 剪辑节奏 ASL 3-4s** ★"6s 一镜看疲劳"问题的答案
- 病灶:6s 静止单镜;好视频是特写↔全景快速硬切。
- 决策:当代电影平均镜头长度 2.5-4s(动作段 <2s);**静止镜一律 ≤4s**;同一场景 ≥3 镜远近交替硬切、对话正反打、关键情绪插反应镜;>4s 必须是运动镜头且有叙事理由(一镜到底只留给情绪释放);时长曲线=情绪(恐惧慢/搏斗快/支点停/释放放)。
- 落点:铁律 3/4;G8/G11(固定>4s=error)/G12(ASL>4.5s=error,镜头组按切数折算)/G13(场景<3镜=warn)。

**8. AI 默认慢漂移必须显式对抗** ★"节奏不对总是缓缓拉镜"问题的答案
- 病灶:不写运动时,模型默认输出缓慢漂移运镜+慢动作,毫无速度感。
- 决策:固定镜写**"机位完全锁定,画面无任何漂移与推拉"**;动作镜写**"真实速度,干脆利落,禁止慢动作,禁止缓慢漂移"**;pace 知识块按 mood/motion_hint 召回(快速利落/舒展流畅/静止凝滞);action 字段必须带速度感("猛地转身"而非"转身")。
- 落点:铁律 9;kb `pace` 轴;`assemble_shot_prompts` 节奏注入。

**10. 校验 Gate 零 token + 重拆闭环**
- G1-G14 规则引擎拆镜后自动跑:error 带违规明细打回重拆一次;残留 error 落章节点 `meta.storyboard_validation`(不静默吞掉);warn 落每镜 `meta.validation` 供前端展示。
- 落点:`validate_shot_list`。

**11. 工程教训**
- 长列表 JSON 输出(12-24 镜)必须显式 `max_tokens`,否则提供商默认值截断 JSON(已踩坑);
- 生成时长按模型档位向上取整、剪辑期修剪(Seedance 5/10s 档);
- 枚举白名单只在代码一处定义,技能文本不得复制枚举(防漂移);
- **ARK 生图不支持 negative 参数**——版式/排除类约束必须写进正向词("画面中只有这一个角色,无文字标签");
- ARK 生图存在瞬时 400(同提示词重试即成功),`generate_image` 已内置 2 次退避重试;
- **要素外貌提示词要避免歧义词**:实测"束冠"被理解为"戴王冠"(本意束发)——外貌词生成/校验时排多义词。

**11c. 生物要素三条铁律(巡夜事故,2026-07-09)**
- **非人形生物必须有设定图,否则画风必崩**(纯文字生成的发光鳐鱼→卡通风,与写实人物同框割裂);
- **生物用专用版式块**("生物设定图":俯/侧视+体型比例参照+皮肤纹理特写)——人形版式的"三视图/表情表"词汇会诱发**拟人化身乱入**(凭空出现白眼老人);
- 生物外貌词带尺度锚("体型远大于人类,巨物压迫感")与写实锚("photorealistic marine megafauna, absolutely not cartoon"——ARK 无 negative,反卡通必须写进正向词);
- 要素 meta.形态="生物" 触发专用版式(element_sheet 自动选择);**缺设定图的要素在镜级生成前由 worker 自动补齐**(`_ensure_element_sheets` 前置环节,补齐后自动重装配拾取短引用)。

**11b. 角色卡三轮收敛实录(大长老,2026-07-09)**
- v1:凭空小男孩+表情表动漫混风+乱码文字 → 修法:约束进正向词(ONE single character/no text/同风格表情);
- v2:乱码与混风消失,动作 pose 仍漂移成年轻人 → 修法:pose 加"identical face, age, build and costume";
- v3:全收敛(高髻正确/全部面板同一人/汉字标签正确)。**版式约束的每个面板都要显式绑定"同一人"**。
